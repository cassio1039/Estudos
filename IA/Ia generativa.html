Machine Learning

Machine learning é a capacidade de aprendizagem de dados a fim de melhorar o desempenho e praticidade da tarefa proposta.

Deep Learning

Deep learning é um subconjunto do machine learning que simula redes neurais artificiais para simular um cérebro humano.

Uma rede neural é um método que utiliza várias camadas para processar informações.

Padrões

Padrões são a identificação a uma repetiçãode um comportamento de um determinado sistema

Aprendizado

Supervisionado: É como se fosse uma espécie de professor, onde ele recebe os resultados

Não Supervisionado: É como se fosse um aluno que aprende sozinho ao longo do tempo sem nenhum tipo de assistência

Algoritmos

em algoritmos temos classificação, regressão e clusterização.

classificação: é o processo de identificar a qual categoria um dado pertence.

regressão: é o processo de identificar numéricamente aqueles dados.

clusterização: é o processo de identificar padrões e agrupá-los em categorias.

otimização:escolhe entre os diversos tipos de dados até chegar em uma resposta satisfatória
