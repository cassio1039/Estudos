MySQL

MySQL tem comandos específicos para várias situações:

DDL: Tipo de definição, onde você pode criar banco de dados, alterar tabelas

DML: Tipo de manipulação, onde você pode inserir, atualizar e excluir dados

DQL: Tipo de consulta, onde você pode selecionar dados

DCL: Tipo de controle, onde você pode conceder ou revogar privilégios

DTL: Tipo de transação, onde você pode gerenciar transações tendo como características principais o conceito de atomicidade, consistência, isolamento e durabilidade (DICA).

Durabilidade: Característica que garante que as transações sejam permanentemente armazenadas no banco de dados, mesmo em caso de falhas do sistema.

Isolamento: Característica que garante que as transações sejam executadas de forma independente, sem interferir umas nas outras.

Atomicidade: Característica que garante que as transações sejam executadas como uma unidade completa, ou seja, todas as operações são concluídas com sucesso ou nenhuma é concluída, nada podendo ficar pela metade.

Consistência: Característica que garante que as transações mantenham a integridade dos dados, respeitando todas as regras de negócio.
